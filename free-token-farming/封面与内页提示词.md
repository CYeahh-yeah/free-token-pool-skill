## 正式封面：必须由内置浏览器 kmage 图生图完成

打开 ChatGPT 内置浏览器里的 kmage STUDIO 网页，选图生图，上传 `05_ContentOS/AI学术博主/Xiaohongshu/视觉资产/【AI号】封面底版.jpeg` 作身份参考。网页当前只给竖图 2:3，把标题和人物放在中央 3:4 安全区。

生产提示词变量：

- 主标题两层：`我把免费模型` / `搭成了统一池`（合计 12 字，黑字与番茄橙交替，奶油白贴纸轮廓）。
- 副标题手撕纸条：`多账号签到，基本实现 token 自由`。
- 信息卡：`WorkBuddy 多账号` / `hy3 限时 0 credits` / `9router 统一路由` / `各类 Agent 可调用`。
- 底部番茄橙行动条：`文末链接领取 Skill + 源码`。
- 人物与场景：本人真实身份、暖木色书房工作台、操作电脑、闭嘴不露牙、真实皮肤质感、眼睛无遮挡；奶油白描边与轻微硬阴影；不添加第二个人。
- 装饰：纸张便签、手撕边、马克笔下划线、1 条主箭头、少量青柠绿勾号和暖黄星标；装饰不挡脸和中文。
- 品牌：`Yeahh博士` 小奶油白贴纸，右下或左上；不加科技蓝、霓虹、机器人、发光大脑或 SaaS 卡片阵列。
- 中文必须准确可读；若有错字重新生成，不用 HTML/CSS 覆盖修字。

验收：本人脸部相似度须由用户确认；缩到 360 px 宽主标题仍可读；中文无错字；闭嘴不露牙；没有额外人物、畸形手势或脸遮挡；关键信息都在 3:4 中央安全区。

## 内页：确定性排版，不放本人人像

统一变量：1080 × 1440，奶油纸底 `#FFF8EC` / `#F5E8D0`，黑字 `#111111`，番茄橙 `#FF4B1F`，青柠绿 `#A7D400`，安全边距 80 px；内页标题 68–82 px，正文不小于 32 px；页码统一 `2/6` 到 `6/6`；每页只讲一个结论。

每页提示词（交给排版脚本或设计 Agent）：

1. `2/6 WorkBuddy 多账号签到`：主结论“积分叠加，日常用量基本实现 token 自由”。表格写 `hy3 x0.00 credits / 限时折扣`，`glm-5.3-flash x0.06`，`hy4-preview x0.29`，`hy4-flash 未收录`。底部标：限时折扣不是永久承诺，本地 cost=0 不是官方免费证明。
2. `3/6 平台实测分层`：三列表格按“平台 / 当前状态 / 路由与边界”写六平台；Qoder 写活动未开放、TRAE 写 `9074` 未到账、商汤写等邀请码；单独提示 HTTP 200 不等于领取到账。
3. `4/6 各类 Agent 都能调用`：流程 `本人登录 → 官方回读 → 9router free-pool → Agent`；列出 Hermes、TRAE、WorkBuddy 额度、Codex、Claude Code、Gemini CLI、OMB、Python/Node；写 Magpie 可选但非必需。
4. `5/6 每日巡检证据链`：五条带编号的工作流，强调官方状态回读、WorkDaddy 跳过当日成功账号、`checked_in=true` 才算到账、`DISABLED` 不领取、短 chat 要有可见回复；失败不兜底付费。

所有关键文字由确定性排版生成；不要让生图模型写表格、模型 ID、数字或文件名。内页不出现用户人像、虚构余额、未验证的“100 Credits 已到账”和“无限 token”。

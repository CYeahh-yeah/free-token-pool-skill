# Free Token Farming Skill · 中文安装指南

## 朋友拿到后的最短路径

1. 解压 `free-token-farming-skill.zip`，把整个 `free-token-farming/` 文件夹放到 `~/.codex/skills/`。
2. 确认 `node --version` 至少 22，`python3 --version` 可用，9router 已跑在 `127.0.0.1:20128`。
3. 打开 Codex，粘贴这一句：

   > 用 $free-token-farming 带我从零检查平台额度，先只做只读盘点，不登录、不写 Key、不改默认模型；确认我本机依赖齐了，再一项一项带我接入 free-pool。

4. Agent 会按 `安装说明.md` 检查依赖、跑 `bash assets/install.sh`、带你逐平台登录，并把官方状态回读和路由真实回复分开报告。
5. 登录、验证码、实名、协议、设备授权由本人完成。Key 只填本机表单或本机 0600 文件，不贴聊天、不进仓库。

## 包内有什么

- `SKILL.md` 与 `references/`：中文步骤、平台状态、模型计费证据、Agent 接入、每日巡检边界。
- `安装说明.md`：架构图、依赖清单、目录树、首次提示语、逐步安装、验收、回滚和常见误判。
- `assets/vendor/`：四组展开源码（`free-token-hub`、`trae-cn-bridge`、`workbuddy-9router`、`workdaddy-local`）。
- `assets/install.sh`、`assets/install-launch-agents.sh`：复制到当前用户目录；把 `__HOME__` / `__NODE__` 替换成当前机器路径。
- `assets/launch-agents/*.xml`：平台接受的 LaunchAgent 模板，安装后生成 `.plist`。
- `LICENSES/` 和 `NOTICE.md`：AGPL-3.0-or-later、MIT 和上游归属。
- `小红书正文.md`、`封面与内页提示词.md`：发布素材备份。

## WorkBuddy 重点

WorkBuddy 多账号本地签到是收益最大的一条，积分叠加后日常用量基本实现 token 自由。本人要在 WorkDaddy 面板启用 `daily-account-checkin` 预设，Agent 不替你注册账号或伪造签到。当前 `hy3` 为 `x0.00 credits` 且标“限时折扣”，`glm-5.3-flash x0.06`、`hy4-preview x0.29`，没有 `hy4-flash`。平台规则会变，交付时重新核官方配置，不承诺永久免费或无限额度。

## 每日自动化完成后的一句话

> 每天运行 $free-token-farming 巡检：先打开魔搭已登录用量页等待真实余额，只有官方两项“今日已完成”同时可见才记录 daily-complete；再运行 hub.py run，核 TRAE/Qoder 官方资格、WorkBuddy 账本和各路由；正常静默，只在登录失效、新失败或明确额度耗尽时通知我。

具体自动化由 Agent 通过 `automation_update` 创建。电脑关机或 Codex 没运行时不会补跑。

## 停用

`launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/<label>.plist` 停后台服务；在 9router 中只改 `free-pool` 组合，恢复前备份 `~/.9router/db/data.sqlite`。不改 Hermes/OMB/WorkBuddy 默认模型，不启用付费回退。
